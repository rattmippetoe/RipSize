# RipSize

RipSize is a Supernote plugin being rebuilt from scratch for the current Supernote plugin runtime.

## Baseline

- React Native 0.79.2
- React 19.0.0
- sn-plugin-lib 0.1.65
- Android SDK 35 / Build Tools 35.0.0
- NDK 27.1.12297006

This repository is the authoritative source for the new RipSize implementation. Previous RipSize implementations are intentionally not part of this codebase.

Generic Supernote development guidance is vendored under `.agents/skills/supernote-plugin-dev/`; see `AGENTS.md` before making SDK-level changes.
